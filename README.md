# calculadora-projeto1
Calculadora simples implementada em Bash e Python
## Como executar o calculadora.sh
Dê permissão de execução ao arquivo:
   '''chmod +x calculadora.sh'''
Execute o script:
   '''./calculadora.sh'''
Digite o primeiro número, o segundo número e o símbolo da operação desejada quando solicitado.
## Como executar o calculadora.py
Execute o script:
   '''python3 calculadora.py'''
Digite o primeiro número, o segundo número e o símbolo da operação desejada quando solicitado.
